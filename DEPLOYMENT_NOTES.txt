IMPORTANT CHECK AFTER DEPLOYMENT:
- Verify Firestore Rules are deployed. Order updates require the signed-in user's users/{uid} document to have role="admin" and status="active". If the order update still fails, inspect the browser console and Firebase Rules/permissions.
- Verify pack sizes and stock fields on product and cart/checkout pages before enabling pack-size-dependent pricing. The admin editor now stores packSizes and inStock; each pack size needs its own price if prices differ.
- The website uses Firebase project sweet-and-sour-aa364. Confirm the Firebase project's authorized domains include the deployed domain.
